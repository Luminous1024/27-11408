# C语言核心进阶：位运算与文件操作

## 1. 位运算（Bitwise Operations）

位运算直接对整型数据的二进制位进行操作，是底层编程、嵌入式开发、权限控制等场景的核心技能。

### 1.1 位运算符

| 运算符  | 名称   | 示例           | 说明                                             |
| ---- | ---- | ------------ | ---------------------------------------------- |
| `&`  | 按位与  | `c = a & b`  | 对应位均为1时结果为1，否则为0。常用于**清零**特定位或**取出**特定位。       |
| `\|` | 按位或  | `c = a \| b` | 对应位至少有一个为1时结果为1。常用于**置位**（将某些位设为1）。            |
| `^`  | 按位异或 | `c = a ^ b`  | 对应位不同为1，相同为0。可用于**翻转**特定位或实现**无临时变量交换**。       |
| `~`  | 按位取反 | `c = ~a`     | 单目运算符，将每一位取反（0变1，1变0）。                         |
| `<<` | 左移   | `c = a << n` | 将a的二进制位左移n位，低位补0。相当于乘以2^n（需注意溢出）。              |
| `>>` | 右移   | `c = a >> n` | 将a的二进制位右移n位。**无符号数**高位补0，**有符号数**通常补符号位（算术右移）。 |

### 1.2 什么是“对应位”？

“对应位”是指两个数在二进制表示中**相同数位**上的位。

例如：  
`x = 5`（二进制 `0101`），`y = 3`（二进制 `0011`）。  
从右向左（第0位为最低位）对比：

| 位的位置 | x的位 | y的位 | 说明       |
|----------|-------|-------|------------|
| 第0位    | 1     | 1     | 一对对应位 |
| 第1位    | 0     | 1     | 一对对应位 |
| 第2位    | 1     | 0     | 一对对应位 |
| 第3位    | 0     | 0     | 一对对应位 |

按位运算符（`&`、`|`、`^`）都是**逐对**对“对应位”进行运算。

### 1.3 操作数类型

- 仅支持**整型**（`char`、`short`、`int`、`long` 以及 `unsigned` 版本）。
- 操作时会进行**整型提升**（`char`、`short` 会被提升为 `int`），结果类型为提升后的类型。

### 1.4 常用技巧

```c
// 1. 置位（将第3位设为1）
a |= (1 << 3);

// 2. 清零（将第3位设为0）
a &= ~(1 << 3);

// 3. 翻转（第3位取反）
a ^= (1 << 3);

// 4. 检查某位是否为1
if (a & (1 << 3)) { ... }

// 5. 利用异或交换两数（无需临时变量）
a ^= b;
b ^= a;
a ^= b;
```

### 1.5 与逻辑运算符的区别

| 运算符     | 类别     | 结果类型 | 示例                 |
| ---------- | -------- | -------- | -------------------- |
| `\|` `&`   | 位运算   | 整型数值 | `5 \| 3` → `7`       |
| `\|\|` `&&` | 逻辑运算 | `0` 或 `1` | `5 \|\| 3` → `1`（真） |

## 2. 文件操作（File I/O）

C语言通过标准库 `<stdio.h>` 提供文件操作函数，支持**文本文件**和**二进制文件**的读写。

### 2.1 文件打开模式

```c
FILE *fopen(const char *filename, const char *mode);
```

| 模式   | 含义                                                         |
| ------ | ------------------------------------------------------------ |
| `"r"`  | 只读打开文本文件，文件必须存在。                             |
| `"w"`  | 只写创建文本文件，若文件存在则清空内容。                     |
| `"a"`  | 追加写文本文件，文件指针定位到末尾。                         |
| `"rb"` | 只读打开二进制文件。                                         |
| `"wb"` | 只写创建二进制文件，存在则清空。                             |
| `"ab"` | 追加写二进制文件。                                           |
| `"r+"` | 读写打开文本文件，文件必须存在。                             |
| `"w+"` | 读写创建文本文件，存在则清空。                               |
| `"a+"` | 读/追加写文本文件，初始指针在末尾。                          |
| 加`b`  | 表示二进制模式（如 `"w+b"` 表示读写二进制文件，存在则清空）。 |

### 2.2 二进制读写函数

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);
size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
```

- `ptr`：数据缓冲区指针。
- `size`：每个元素的字节数。
- `count`：要读/写的元素个数。
- 返回值：实际成功读/写的元素个数（通常等于 `count` 表示成功）。

### 2.3 文件指针定位

| 函数                         | 说明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `rewind(FILE *stream)`       | 将文件位置指针重置到文件开头。                               |
| `fseek(FILE *stream, long offset, int origin)` | 将指针移动到 `origin + offset` 处。<br>`origin` 可以是：<br> - `SEEK_SET`：文件开头<br> - `SEEK_CUR`：当前位置<br> - `SEEK_END`：文件末尾 |
| `long ftell(FILE *stream)`   | 返回当前文件位置指针相对于文件开头的偏移量（字节数）。       |
| `int feof(FILE *stream)`     | 判断是否到达文件末尾。                                       |

### 2.4 典型流程

1. **打开文件**：`fopen`
2. **读写操作**：`fread` / `fwrite`（二进制）或 `fprintf` / `fscanf`（文本）
3. **定位指针**（可选）：`rewind` / `fseek`
4. **关闭文件**：`fclose`

### 2.5 综合示例解析

下面这道题将位运算与文件操作融合考查：

```c
#include <stdio.h>

int main()
{
    FILE *fp;
    int k, a[6]={4,5,6,3,2,1}, b[6];
    fp = fopen("d.dat", "w+b");
    for(k=0;k<6;k++)
        fwrite(&a[5-k], sizeof(int), 1, fp);  // 逆序写入：1,2,3,6,5,4
    rewind(fp);                               // 指针回到开头
    fseek(fp, sizeof(int)*2, SEEK_CUR);       // 跳过前2个int（即1和2）
    fread(b, sizeof(int), 4, fp);             // 读取后续4个int：3,6,5,4
    fclose(fp);
    for (k=0;k<4; k++)
        printf("%d.", b[k]);                  // 输出：3.6.5.4.
    return 0;
}
```

**核心考点**：
- `"w+b"` 模式：清空并创建二进制文件。
- `fwrite` 写入数据的顺序（循环逆序）。
- `rewind` 重置指针。
- `fseek` 相对于当前指针移动。
- `fread` 从当前位置读取指定数量的元素。

## 3. 总结

| 知识点           | 关键函数/运算符          | 常见场景                     |
| ---------------- | ------------------------ | ---------------------------- |
| **位运算**       | `&` `\|` `^` `~` `<<` `>>` | 硬件寄存器操作、权限掩码、快速数学 |
| **文件指针定位** | `rewind` `fseek` `ftell` | 随机访问二进制文件、解析文件头 |
| **二进制读写**   | `fread` `fwrite`         | 保存/加载结构体数组、数据持久化 |

掌握位运算与文件操作，是深入理解C语言底层能力的关键一步。在实际嵌入式、系统编程中，二者常常配合使用（如直接操作设备文件、解析二进制协议等）。
