# 完全背包问题：从识别到解法的完整指南

>[!definition]
>**完全背包问题**是背包问题的一种变体，其定义为：给定一个容量为 `V` 的背包和 `N` 种物品，每种物品有无限多件，每件物品的体积为 `w[i]`，价值为 `v[i]`。问如何选择物品放入背包，使得总体积不超过 `V` 且总价值最大。

>[!info] 与 0-1 背包的区别
>- **0-1 背包**：每种物品只有一件，要么选要么不选。
>- **完全背包**：每种物品有无限件，可以重复选择。
>- 这一区别直接导致了两者在动态规划遍历顺序上的不同。

>[!question] 如何识别题目为完全背包问题？
>当题目中出现以下特征时，可考虑使用完全背包模型：
>- 有若干种“物品”，每种物品可以被无限次使用（或无限供应）。
>- 有一个“容量”限制（如总金额、总时间、总空间等）。
>- 目标是求最大价值、最小花费、方案数等。
>- 常见场景：找零钱（硬币无限）、凑金额、组合问题、资源分配等。
>
>例如本题“买饮料”：三种饮料无限供应，总金额为 N，求最少小费（即最大化花掉的钱），就是典型的完全背包问题。

>[!solution] 通用解决方案：动态规划
>完全背包问题的标准解法采用动态规划，其核心思想与 0-1 背包类似，但遍历顺序需调整。
>
>**1. 状态定义**  
>设 `dp[i][j]` 表示前 `i` 种物品在容量为 `j` 的背包中能获得的最大价值。但通常优化为一维数组。
>
>**2. 递推公式**  
>对于第 `i` 种物品，可以选择 0 件、1 件、2 件……直到装不下。因此：
>\[
>dp[j] = \max(dp[j], dp[j - w[i]] + v[i]) \quad \text{（一维形式，正序遍历）}
>\]
>注意：与 0-1 背包不同，0-1 背包需要倒序遍历以保证每件物品只选一次，而完全背包正序遍历允许重复选择。
>
>**3. 初始化**  
>通常 `dp[0] = 0`，其余为负无穷（求最大价值）或 0（求方案数等），根据题目要求调整。
>
>**4. 遍历顺序**  
>外层循环遍历物品，内层循环**正序**遍历容量（从 `w[i]` 到 `V`），这样 `dp[j - w[i]]` 可能已经包含了当前物品多次选择的情况，从而实现无限取用。
>
>**5. 空间优化**  
>使用一维数组 `dp[0..V]` 即可，省去物品维度，降低空间复杂度。

>[!code] 代码模板（C语言）
>```c
>// 求最大价值
>int knapsackComplete(int V, int N, int w[], int v[]) {
>    int dp[V+1];
>    memset(dp, 0, sizeof(dp));  // 根据题目初始化
>    for (int i = 0; i < N; i++) {
>        for (int j = w[i]; j <= V; j++) {
>            // 正序更新
>            if (dp[j - w[i]] + v[i] > dp[j])
>                dp[j] = dp[j - w[i]] + v[i];
>        }
>    }
>    return dp[V];
>}
>```
>注意：如果求的是最小花费或方案数，需调整递推关系和初始值。

>[!example] 例题：买饮料问题
>**题目描述**：三种饮料价格分别为 150、200、350 分，无限供应，总金额 N 分，求最少小费（即花掉的最大金额）。
>**识别**：物品无限，有总金额限制，目标是最大化花掉的钱（等价于求最大价值，其中价格=体积，价值=价格）。
>**解法**：
>```c
>void calculateMinTip(int N) {
>    int prices[3] = {150, 200, 350};
>    int dp[10001] = {0};
>    dp[0] = 1;  // 此处用布尔值表示能否凑出金额
>    for (int k = 0; k < 3; k++) {
>        int p = prices[k];
>        for (int i = p; i <= N; i++) {
>            if (dp[i - p]) dp[i] = 1;
>        }
>    }
>    int max_spent = 0;
>    for (int i = N; i >= 0; i--) {
>        if (dp[i]) { max_spent = i; break; }
>    }
>    printf("%d\n", N - max_spent);
>}
>```
>**关键点**：本题不要求最大价值，而是求最大可凑金额，因此用布尔数组记录可行性。本质仍是完全背包。
>
>**如何快速识别本题为完全背包问题？**
>1. **物品无限**：题目中三种饮料均可无限购买，没有数量限制，这是完全背包的核心特征。
>2. **容量约束**：总金额 N 是上限，相当于背包容量。
>3. **目标转化**：要求最少小费，即最大化花掉的钱。花掉的钱等于所选饮料价格之和，因此问题转化为：在不超过 N 的前提下，用无限供应的三种面额（150、200、350）能凑出的最大金额是多少？这正是完全背包求最大价值（此处价值等于价格）的模型。
>4. **关键词提示**：题目描述中“多买一点饮料”“尽量少让他赚小费”暗示了要尽可能用足 N，属于典型的背包问题语言。
>
>综上，看到“无限供应”“总额限制”“最优组合”这些要素，即可迅速联想到完全背包。

>[!summary] 总结
>- 完全背包的核心特征是每种物品无限供应。
>- 识别方法：关注“无限”“任意数量”“每种都有很多”等关键词，结合容量限制。
>- 通用解法：一维动态规划，外层物品，内层容量**正序**遍历。
>- 根据问题目标（最大价值、最小花费、方案数等）调整递推公式和初始化。
>- 熟练掌握完全背包模板，并注意与 0-1 背包的遍历顺序区别。

>[!warning] 注意事项
>- 当物品体积为 0 时需特殊处理（一般不会出现）。
>- 求方案数时，递推公式为 `dp[j] += dp[j - w[i]]`，且 `dp[0] = 1`。
>- 注意数据范围，避免数组越界。
