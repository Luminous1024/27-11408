# C语言二维数组元素内存地址计算

## 内存布局
C语言中的二维数组采用**行优先**方式存储，即先存放第0行的所有元素，接着第1行、第2行……每行内部按下标递增连续存放。整个数组占用一段**连续的线性内存空间**。

假设声明：
```c
int a[3][4];   // 3行4列的整型数组
```
则在内存中的布局如下（每个int占4字节）：
```
行0: a[0][0] a[0][1] a[0][2] a[0][3]
行1: a[1][0] a[1][1] a[1][2] a[1][3]
行2: a[2][0] a[2][1] a[2][2] a[2][3]
```
所有元素按行顺序连续存放，行与行之间无空隙。

---

## 地址计算公式
设数组首地址（即 `a[0][0]` 的地址）为 `base`（十六进制），元素类型大小为 `sizeof(T)` 字节，则元素 `a[i][j]` 的地址为：

$$
\text{地址} = \text{base} + (i \times N + j) \times \text{sizeof}(T)
$$

- \(i × N + j\)：从数组开头到目标元素的元素个数（按一维索引）
- 乘以元素大小得到字节偏移量

> 在32位系统中，地址通常用8位十六进制数表示（如 `0x1000` 实际为 `0x00001000`），64位系统则用16位。下文示例采用8位十六进制以便阅读。

---

## 实例分析（贴合实际）

### 代码环境假设
- 操作系统：32位 Linux / Windows
- 数组 `int a[3][4]` 的首地址为 `0x00001000`
- `sizeof(int) = 4` 字节

### 手动计算 `a[1][2]` 的地址
```c
int a[3][4];
// 假设基址为 0x00001000
int base = 0x00001000;          // 实际中通过 (int)a 获得
int offset = (1 * 4 + 2) * 4;   // (行1*4列 + 列2) * 4字节 = 24 = 0x00000018
int addr = base + offset;       // 0x00001000 + 0x18 = 0x00001018
printf("a[1][2] 地址: 0x%08x\n", addr);  // 输出 0x00001018
```

### 内存实际分布
```
地址范围        元素
0x00001000  →  a[0][0]
0x00001004  →  a[0][1]
0x00001008  →  a[0][2]
0x0000100C  →  a[0][3]
0x00001010  →  a[1][0]
0x00001014  →  a[1][1]
0x00001018  →  a[1][2]   <-- 目标元素
0x0000101C  →  a[1][3]
0x00001020  →  a[2][0]
0x00001024  →  a[2][1]
0x00001028  →  a[2][2]
0x0000102C  →  a[2][3]
```

### 在程序中验证
```c
#include <stdio.h>

int main() {
    int a[3][4] = {0};
    printf("数组首地址: %p\n", a);              // 例如 0x7ffd12345678（实际值）
    printf("a[1][2] 地址: %p\n", &a[1][2]);
    
    // 将地址转为整数计算偏移（仅演示原理，不推荐直接转换）
    unsigned long base = (unsigned long)a;
    unsigned long offset = (1*4 + 2) * sizeof(int);
    unsigned long computed = base + offset;
    printf("计算地址: 0x%016lx\n", computed);   // 应与 &a[1][2] 一致
    return 0;
}
```
> 注意：实际运行时的地址可能为64位（如 `0x7ffd12345678`），计算原理完全相同。

## 指针与多维数组
- 数组名 `a` 在表达式中退化为指向其首行的指针，类型为 `int (*)[4]`。
- `a + i` 指向第 `i` 行，移动 `i * 4 * sizeof(int)` 字节。
- `*(a + i)` 得到第 `i` 行首元素的指针（类型 `int*`），即 `&a[i][0]`。
- `*(a + i) + j` 即为 `&a[i][j]`。

因此以下三种写法等价：
```c
&a[i][j]
*(a + i) + j
&(*(a + i))[j]   // 语法稍显晦涩
```

---

## 总结
1. C语言二维数组内存布局：**行优先、连续存放**。
2. 地址计算：`&a[i][j] = 数组首地址 + (i * 列数 + j) * 元素大小`。
3. 实际调试时地址通常以十六进制显示，长度取决于系统（32位为8位，64位为16位），但计算公式通用。
4. 理解指针运算有助于深入掌握多维数组操作。
