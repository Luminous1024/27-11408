# 手机话费问题（空瓶换汽水变体）

>[!quote] 问题描述
>每天消费1元，每消费满K元可获赠1元。初始有M元，问最多能用多少天？  
>输入多组M、K（2 ≤ K ≤ M ≤ 1000），以`0 0`结束，每行输出一个整数天数。

>[!summary] 核心思路
>- 初始M元直接消费 → M天。
>- 每获得一次奖励（1元），这1元也能消费，并可能继续产生奖励。
>- 设奖励次数为 $t$，则总天数 $d = M + t$。
>- 问题转化为求最大的有效奖励次数 $t$。

>[!definition] 关键点：奖励的有效性
>奖励是在消费满 $K$ 元后**立即获得**，但只能用于**未来的消费**。  
>每获得一次奖励，实际从本金中**净支出** $K-1$ 元（因为奖励的1元也花掉了）。  
>因此，$t$ 次奖励总共消耗本金 $(K-1)t$ 元。
>
>为了保证最后一次奖励能被用于消费，需要确保在获得最后一次奖励后还有至少1元可用（这1元正是这次奖励本身），即消耗的本金不超过 $M-1$ 元，等价于本金至少比净支出多1元：  
>$$
>M \ge (K-1)t + 1 \quad \Rightarrow \quad (K-1)t \le M-1
>$$
>解得：
>$$
>t \le \frac{M-1}{K-1}
>$$
>最大整数 $t$ 为：
>$$
>t = \left\lfloor \frac{M-1}{K-1} \right\rfloor
>$$
>总天数：
>$$
>d = M + \left\lfloor \frac{M-1}{K-1} \right\rfloor
>$$

>[!question] 为什么是 $M-1$ 而不是 $M$？
>如果直接用 $t = \left\lfloor \frac{M}{K-1} \right\rfloor$，当 $M$ 是 $K-1$ 的倍数时，会得到 $t = \frac{M}{K-1}$。此时 $(K-1)t = M$，即消耗了全部本金。但实际过程无法实现这么多次奖励，因为要获得最后一次奖励，需要再消费 $K$ 元，而本金已耗尽，无法支撑到那一刻。例如 $M=4, K=3$，用 $M/(K-1)=2$，则总天数 $d=6$。但模拟发现，获得第一次奖励后只剩2元，再花2天只能到第5天，无法达到第6天，因此实际只能获得1次奖励。  
>用 $M-1$ 则自动得到 $t = \left\lfloor \frac{3}{2} \right\rfloor = 1$，避免了这种不可行的情况。

>[!tip] 通俗理解
>- 每获得一次有效奖励，相当于用 $K-1$ 元本金换来 $K$ 天的消费（其中1天是奖励来的）。
>- 要获得 $t$ 次有效奖励，本金至少需要 $(K-1)t + 1$ 元。
>- 给定 $M$ 元，最大 $t$ 就是 $(M-1)$ 除以 $(K-1)$ 的整数部分。

>[!example] 例子验证
>1. **$M=4, K=3$**  
>   $t = (4-1)/(3-1) = 3/2 = 1$（整数除法），$d=4+1=5$。  
>   模拟：4→花3得1→剩2→花2，共5天。
>2. **$M=5, K=3$**  
>   $t = 4/2 = 2$，$d=7$。  
>   模拟：5→花3得1→剩3→花3得1→剩1→花1，共7天。
>3. **$M=6, K=4$**  
>   $t = 5/3 = 1$，$d=7$。  
>   模拟：6→花4得1→剩3→花3（无法再得奖励），共7天。

>[!code] C语言代码
>```c
>#include <stdio.h>
>int main() {
>    int M, K;
>    while (scanf("%d %d", &M, &K) == 2 && (M || K)) {
>        int days = M + (M - 1) / (K - 1);  // 整数除法自动向下取整
>        printf("%d\n", days);
>    }
>    return 0;
>}
>```

>[!warning] 注意事项
>- 输入结束条件：$M=0$ 且 $K=0$。
>- 公式中除法为整数除法，C语言中直接使用 `/` 即可。
>- 理解 $(K-1)$ 的含义：每次奖励对应的本金净消耗。

>[!summary] 总结
>本问题通过分析奖励次数与本金消耗的关系，得到简洁公式。核心在于用 $M-1$ 确保最后一次奖励能被实际使用，避免了因本金刚好耗尽而无法获得最后一次奖励的情况。
