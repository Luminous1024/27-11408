**内存对齐**（Memory Alignment）是计算机系统为了提升内存访问效率，而对数据在内存中的存放地址所做出的一种限制。简单来说，它要求特定类型的数据只能存储在内存中某些特定的地址上（通常是该数据类型大小的整数倍地址）。

以下是关于内存对齐的详细解释：

### 1. 为什么需要内存对齐？

现代计算机的CPU并不是一个字节一个字节地读取内存的，而是以**字（Word）**为单位进行读取。例如，在32位系统中，一个字是4字节；在64位系统中，一个字通常是8字节。

-   **没有对齐的例子**：
    假设一个 4 字节的 `int` 类型整数，存储在地址 3 到 6（未对齐，因为起始地址 3 不是 4 的倍数）。
    -   CPU 要读取这个整数，可能需要先读取地址 0-3（得到 3，4 位置的数据），再读取地址 4-7（得到 5，6 位置的数据），然后剔除不需要的字节，最后拼接成一个完整的整数。
    -   这个过程需要两次内存访问和一次计算，效率较低。

-   **对齐的例子**：
    如果这个 `int` 存储在地址 4 到 7（对齐，起始地址 4 是 4 的倍数）。
    -   CPU 只需一次内存访问，直接读取地址 4-7，就能拿到完整的整数。
    -   速度更快。

**核心目的：**

1.  **提高访问速度**：确保任何基本数据类型的地址都是其大小的整数倍，使得CPU可以在一次总线周期内完成数据读写，避免跨片读取带来的性能损耗。
2.  **原子性操作**：对齐的数据可以保证读或写操作在一个CPU周期内完成，不会被其他线程或CPU核心打断中间状态。
3.  **硬件兼容性**：某些硬件平台（如ARM、MIPS）根本**不支持**非对齐的内存访问，一旦出现未对齐的情况，程序会直接崩溃。

### 2. 内存对齐的规则

内存对齐主要遵循两个规则：**对齐系数**和**结构体整体对齐**。

#### 规则一：成员对齐
每个成员变量的起始地址必须是 **“自身对齐值”** 的整数倍。

-   **自身对齐值**：通常是该数据类型所占字节数。
    -   `char` (1 byte)：地址必须是 1 的倍数（任何地址均可）。
    -   `short` (2 bytes)：地址必须是 2 的倍数。
    -   `int` (4 bytes)：地址必须是 4 的倍数。
    -   `double` (8 bytes)：地址必须是 8 的倍数。

编译器为了满足这个规则，会在成员之间**填充（Padding）**无意义的字节。

#### 规则二：结构体总大小对齐
整个结构体的总大小，必须是 **“最大成员对齐值”** 的整数倍。这是为了确保结构体数组中的每一个元素都能满足对齐规则。

### 3. 图解示例

考虑下面这个结构体（假设在32位系统，对齐系数为4）：

```c
struct Example {
    char a;   // 1 byte
    int b;    // 4 bytes
    char c;   // 1 byte
};
```

如果直接计算大小，1 + 4 + 1 = 6 字节。但实际输出 `sizeof(struct Example)` 通常是 **12 字节**（取决于编译器，GCC通常是12）。内存布局如下：

| 地址偏移 | 存储内容 | 说明 |
| :--- | :--- | :--- |
| **0** | `a` | 存放 `char a` |
| **1** | 填充 | 为了满足规则1，`int b` 必须从4的倍数（4）开始，所以1-3被填充 |
| **2** | 填充 | |
| **3** | 填充 | |
| **4 - 7** | `b` | 存放 `int b` |
| **8** | `c` | 存放 `char c` |
| **9** | 填充 | 为了满足规则2，结构体总大小必须是最大成员（int,4）的倍数，当前是9，需填充到12 |
| **10** | 填充 | |
| **11** | 填充 | |

**优化建议：**
将小的成员放在一起，可以减少填充浪费。

```c
struct ExampleOptimized {
    char a;   // 1 byte
    char c;   // 1 byte
    int b;    // 4 bytes
};
```
此时布局：
-   0: a
-   1: c
-   2: 填充（为了让b从4开始）
-   3: 填充
-   4-7: b
总大小 = **8 字节**。节省了 4 字节的空间。

### 4. 如何干预内存对齐

在编程中，可以通过预处理指令来改变默认的对齐规则（虽然通常不建议这样做，除非有特殊需求，如网络协议封包、硬件寄存器映射）。

-   **C/C++ 中的 `#pragma pack(n)`**：
    告诉编译器按照 n 字节对齐。成员的实际对齐值取“自身大小”和“n”中的较小值。

    ```c
    #pragma pack(1)  // 告诉编译器按1字节对齐（取消对齐优化）
    struct PackedStruct {
        char a;
        int b;
        char c;
    };
    #pragma pack()   // 恢复默认对齐

    // sizeof(PackedStruct) 将等于 1+4+1 = 6 字节
    ```

### 总结

内存对齐是**“空间换时间”**思想的典型应用。它通过填充少量的无用字节，保证了CPU访问内存的高效性，是现代编译器默认开启的重要优化机制。在设计结构体时，合理安排成员顺序，可以有效减少内存浪费。
