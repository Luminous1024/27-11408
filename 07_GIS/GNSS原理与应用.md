> [!quiz] 简述协议天球坐标系到协议地球坐标系的转换
> 从协议天球坐标系到协议地球坐标系的转换通常包括以下四个步骤：
> 
> 1. **协议天球坐标系 → 平天球坐标系**：考虑岁差改正。岁差是地球自转轴长期进动引起的天极和春分点缓慢移动，将协议历元（如J2000.0）的坐标系转换到当前历元的平天球坐标系。
> 
> 2. **平天球坐标系 → 真天球坐标系**：考虑章动改正。章动是地球自转轴的周期性摆动，通过章动旋转矩阵得到真天球坐标系，其天极和春分点为瞬时真天极和真春分点。
> 
> 3. **真天球坐标系 → 瞬时地球坐标系**：考虑地球自转。根据格林尼治真恒星时（GAST）旋转地球，将真天球坐标系绕Z轴旋转至瞬时地球坐标系，该坐标系与地球固连但Z轴指向瞬时天球北极，X轴指向格林尼治子午线与赤道交点。
> 
> 4. **瞬时地球坐标系 → 协议地球坐标系**：考虑极移改正。极移是地球自转轴相对于地壳的运动，通过极移旋转矩阵将瞬时地球坐标系转换到协议地球坐标系（如ITRS），其Z轴指向协议地球极（如CIO），X轴指向协议格林尼治子午线。
> 
> 这一系列转换实现了从惯性参考系到地固参考系的精确变换，广泛应用于卫星定位、天文测量等领域。

>[!quiz] 请解释什么是周跳，并描述其在GNSS系统中的影响以及周跳产生的原因？
>**周跳**是指在GNSS载波相位观测中，由于信号失锁导致接收机记录的载波相位整周计数发生跳变或中断的现象。简单来说，就是相位观测值中的整周部分出现了非连续的跳跃。
>
>**影响**：
> - 破坏载波相位观测值的连续性，使得高精度定位（如厘米级RTK、精密单点定位）无法直接获得正确的模糊度参数。
> - 若未检测并修复周跳，将导致定位结果出现分米至米级的误差，甚至解算失败。
> - 需要复杂的周跳探测与修复算法来恢复观测值的完整性。
>
>**产生原因**：
> - **信号遮挡**（如树木、建筑物、桥梁等遮挡卫星信号）。
> - **低信噪比**（如天线受干扰或卫星仰角过低）。
> - **接收机动态剧烈**（高加速度或剧烈振动导致失锁）。
> - **多路径效应**（反射信号与直达信号叠加引起相位异常）。
> - **接收机内部噪声或钟跳**。
> - **电离层闪烁**（快速变化的电离层延迟也可能诱发周跳）。

>[!quiz] 简述固定整周模糊度的原因？
>固定整周模糊度的原因在于：**载波相位测量只能测得不足一周的小数部分，而整周数是未知的**。这一未知整数称为整周模糊度。若不能正确确定其整数值，则无法将高精度的相位观测值（精度毫米级）转化为准确的距离观测值，定位精度只能停留在米级或分米级。只有将模糊度**固定为正确的整数**，才能充分发挥载波相位测量的高精度潜力，实现厘米级甚至毫米级的精密定位。因此，整周模糊度的固定是GNSS高精度定位（如RTK、静态测量、精密单点定位等）的核心步骤。

周跳是GNSS精密定位中必须处理的核心问题之一。以下从定义、成因到探测修复方法进行系统讨论。

### 一、周跳的定义

**周跳**是指在GNSS载波相位观测中，由于某种原因导致接收机内部的**整周计数器发生中断或跳变**。

- **正常情况**：载波相位观测值 $\Phi$ = 整数部分 $N$ + 小数部分 $\Delta\varphi$。计数器持续累加整周数。
- **发生周跳后**：整周计数 $N$ 出现偏差 $\Delta N$（整数），而小数部分 $\Delta\varphi$ 仍然是连续且正确的。

**关键特征**：周跳发生后，后续所有的相位观测值都**平移了同一个整数偏差**，表现为相位序列图上出现一个陡峭的台阶状跳变。

### 二、产生的原因

周跳的根本原因是**接收机锁相环短暂失锁**，具体原因可分为三类：

| 原因类别 | 具体场景 | 特点 |
| :--- | :--- | :--- |
| **1. 信号遮挡** | 树木、桥梁、隧道、高楼遮挡卫星信号。 | 最常见，周跳大小不确定，可能高达数千周。 |
| **2. 低信噪比** | 电离层闪烁、多路径效应严重、卫星仰角极低。 | 信号强度低于接收机跟踪阈值（通常30-40 dB-Hz）。 |
| **3. 接收机动态/故障** | 载体高动态运动（如火箭发射）导致多普勒频移突变；接收机晶振不稳定或处理软件缺陷。 | 可能导致整周计数器硬件重置。 |

### 三、探测与修复方法

#### 1. 主要探测方法

核心思路是构建检验量，利用周跳会导致观测序列“不光滑”的特性来发现它。

| 方法         | 原理与公式                                                                                                                                          | 优点                           | 缺点                                                                        |
| :--------- | :--------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------- | :------------------------------------------------------------------------ |
| **高次差法**   | 对原始相位序列做 \(n\) 次差分。周跳会被差分算子**放大**为奇异值。                                                                                                         | 简单直观，无需双频。                   | 对微小周跳（1-2周）不敏感；受电离层变化干扰。                                                  |
| **多项式拟合法** | 用前 \(m\) 个历元拟合曲线，外推下一历元值与实测值比较。若差值 \(>\epsilon\)（阈值），判为周跳。                                                                                     | 适合单频静态后处理。                   | 依赖数据长度；动态环境下易误判。                                                          |
| **电离层残差法** | **经典双频方法**。$$构造组合：\Phi_{GF} = \lambda_1 \Phi_1 - \lambda_2 \Phi_2$$<br>$$历元间差分：\Delta\Phi_{GF} = \lambda_1 \Delta N_1 - \lambda_2 \Delta N_2$$ | **极其灵敏**（可探测1周小周跳），不受几何距离影响。 | $$若 \lambda_1 \Delta N_1 / \lambda_2 \Delta N_2 约等于频率比(如77/60)，会存在探测盲点。$$ |
| **MW组合法**  | **Melbourne-Wübbena组合**：<br>$$N_W = \Phi_W - R_W$$<br>其中包含宽巷模糊度 \(N_W\)。对 \(N_W\) 做递推平均，突变即周跳。                                                 | 能直接确定**宽巷周跳值**，不受几何和电离层影响。   | 仅能探测宽巷组合的周跳，无法区分是L1还是L2跳了。                                                |
| **三频组合法**  | $$利用BDS/GPS三频数据构造无几何无电离层组合（如 \Delta \Phi_{(0,1,-1)}），噪声极低。$$                                                                                   | 盲点极少，修复成功率极高。                | 需要三频信号支持。                                                                 |

#### 2. 修复策略

探测到周跳后，有两种处理思路：

- **策略A：修复（Repairing）**
    - 目标：求出具体的整数偏差 $\Delta N$，将后续数据**拉回**原连续弧段。
    - 方法：利用上述双频/三频组合观测值解算整数方程组。
    - 结果：**保持了模糊度参数的连续性**，适合高精度静态后处理。

- **策略B：重置（Resetting / Flagging）**
    - 目标：不修复数值，而是在滤波器中引入一个新模糊度参数。
    - 应用：**RTK实时动态定位**中，由于算力限制或模糊度不可靠，直接丢弃旧模糊度，重新初始化该卫星。
    - 结果：定位结果会出现短暂浮动或重收敛过程。

### 四、总结

| 阶段     | 核心逻辑                                                                |
| :----- | :------------------------------------------------------------------ |
| **定义** | 整数计数错乱，小数部分不变。                                                      |
| **原因** | 遮挡、电离层闪烁、高动态。                                                       |
| **探测** | **电离层残差法**（灵敏）与**MW组合法**（稳定）互补使用，是目前GNSS精密软件（如Bernese、RTKLIB）的标配算法。 |
| **处理** | 静态后处理倾向于**修复**以保持弧段长度；实时动态倾向于**重置**参数。                              |

GPS测量的误差源可按来源分为三大类：与卫星有关、与信号传播有关、与接收设备有关。针对不同误差的特性，需要采用从建模改正、硬件优化到差分技术等多层次的方法来应对。其中，**差分技术能最有效地消除大部分公共误差**，而针对**多路径效应等特殊误差**，则需要结合硬件优化和数据处理方法来进行削弱。

下面是各类误差源及对应消除/削弱方法的详细总结：

### 📊 GPS误差源及消除/削弱方法一览

| 误差类别 | 主要误差源 | 产生原因/影响 | 消除或削弱方法 |
| :--- | :--- | :--- | :--- |
| **与卫星有关** | **1. 卫星星历误差**<br>（轨道误差） | 卫星星历给出的空间位置与实际位置的偏差，是重要误差来源。 | - **建模改正**：采用精密星历（如IGS发布的事后精密星历）替代广播星历。<br>- **差分技术**：通过站间求差，消除或减弱其影响。<br>- **参数估计**：将轨道误差作为未知参数在平差中求解。 |
| | **2. 卫星钟差** | 卫星原子钟的钟面时与GPS标准时的差异。即使高精度原子钟，由此引起的等效距离误差也可达**300km**。 | - **模型改正**：利用导航电文中的钟差参数进行修正。<br>- **差分技术**：通过站间求差消除。<br>- **精密产品**：使用IGS等机构提供的精密卫星钟差产品。 |
| | **3. 相对论效应** | 卫星钟与接收机钟因运动速度和重力位不同而产生的相对钟差。 | - **模型改正**：在出厂前已对卫星钟频率进行预设调整，用户端也可用公式进一步修正。 |
| **与信号传播有关** | **4. 电离层延迟** | 信号穿过电离层（50-1000km）时，速度变化、路径弯曲，产生延迟。影响大小与总电子含量(TEC)和信号频率有关，对码和相位观测值影响大小相同，符号相反。 | - **双频/多频改正**：利用延迟与频率平方成反比的特性，通过组合观测值消除一阶项影响（可达**99.9%**）。<br>- **模型改正**：单频接收机用户可使用Klobuchar等经验模型进行修正。<br>- **差分技术**：短基线（<20km）情况下，差分可有效消除。 |
| | **5. 对流层延迟** | 信号通过对流层（约40km以下）时，因大气折射产生的延迟。与气温、气压、湿度相关，对码和相位观测值影响相同。 | - **模型改正**：使用Saastamoinen、Hopfield等模型，并输入实测气象参数进行改正。<br>- **参数估计**：将天顶对流层延迟作为未知参数进行估计。<br>- **差分技术**：短基线差分可有效消除。 |
| | **6. 多路径效应** | 反射信号（来自建筑物、水面等）与直射信号干涉，导致测量偏差。反射信号强度取决于反射源材质。该误差**无法通过差分技术有效削弱**，已成为短基线高精度测量的主要误差源。 | - **硬件优化**：采用扼流圈天线、抗多路径天线；选择开阔无反射环境的测站。<br>- **数据处理**：延长观测时间取均值、采用小波分析、经验模式分解(EMD)等方法；使用基于多相关器的接收机。 |
| **与接收设备有关** | **7. 接收机钟差** | 接收机使用的石英钟与GPS标准时之间的差异。 | - **差分技术**：通过站间单差或星间双差消除。<br>- **参数估计**：将钟差作为未知参数与坐标等一同求解。 |
| | **8. 接收机天线相位中心偏差** | 天线相位中心与几何中心不一致，且随信号方向变化。 | - **模型改正**：使用绝对天线相位中心模型进行改正。<br>- **硬件措施**：使用高质量、相位中心稳定的天线；强制对中。 |
| | **9. 接收机位置误差** | 天线相位中心相对测站标石中心的安置误差。 | - **精确对中整平**：提高天线架设精度。 |
| | **10. 观测噪声** | 接收机内部电路、量化误差等产生的随机误差。 | - **选用高质量接收机**。<br>- **提高信号信噪比**。<br>- **数据平滑滤波**：采用合适的滤波算法（如卡尔曼滤波）。 |

### 🛰️ 差分技术：消除公共误差的核心方法

差分技术是目前应用最广泛、最有效的消除公共误差的方法之一。通过在已知精确坐标的**基准站**和待测的**流动站**之间同步观测，计算并播发误差修正值。

*   **原理**：利用空间相关性，基准站和流动站的**公共误差**（卫星钟差、星历误差、大部分电离层/对流层延迟）**基本一致**，通过求差可以将其大部分消除。该技术可将单GPS系统约**25米**的定位精度提升至米级甚至厘米级。
*   **三种主流差分技术**：
    1.  **位置差分**：直接修正用户站的坐标，是最简单的方法，适用于**100公里以内**的场景。
    2.  **伪距差分**：应用最广泛的差分技术，通过对伪距观测值进行修正，可达到**米级**定位精度。
    3.  **载波相位差分 (RTK)**：精度最高的差分技术，通过处理载波相位观测值，可实时实现**厘米级**甚至**毫米级**的定位精度，是工程测量、地形测图等领域的核心技术。

### 💡 其他重要方法与技术

除了差分技术，一些进阶技术和新兴手段也在不断突破GPS的精度极限。

*   **精密单点定位 (PPP)**：仅需单台接收机，利用**精密星历和钟差产品**，结合**双频消电离层组合**等精细模型，即可在全球范围内实现分米至厘米级的高精度定位。
*   **多系统融合**：通过联合接收GPS、北斗、GLONASS、Galileo等多个卫星导航系统的信号，可以增加可用卫星数量，改善卫星几何分布，从而显著提升定位的精度、可靠性和可用性。
*   **辅助定位技术**：在卫星信号不佳的环境（如城市峡谷、室内），利用**Wi-Fi、基站、惯性导航系统(INS)** 等进行辅助，可显著提升定位精度和连续性。
*   **新兴技术应用**：人工智能（AI）与机器学习技术已开始应用于误差建模和预测；阵列天线技术与自适应波束形成算法能从信号层面直接抑制干扰和反射信号。

### 💎 总结

总的来看，GPS误差的消除是一个系统工程。**差分技术是解决广播星历精度有限和实时大气延迟的有效手段，而精密单点定位（PPP）则代表了不依赖基准站的高精度发展方向。** 对于多路径效应这类“顽固”误差，则需要结合硬件设计与复杂的信号处理技术来应对。未来，随着多系统融合、AI技术的深入应用，GNSS定位的精度和可靠性将进一步提升。

GPS信号可以看作是一个三层结构的“信息包裹”：最底层是**载波**，它负责承载信息；中间层是**测距码**，用于区分卫星和测量距离；最上层是**导航电文**，包含了计算卫星位置所需的各类数据。这三层信号通过一种叫做“调制”的技术结合在一起，从卫星发射到地面。

---

### 📡 载波：信号的基础载体
*   **L1**：频率为 **1575.42 MHz**，波长约 19 cm。主要承载 C/A 码、P(Y) 码和现代化的 M 码。
*   **L2**：频率为 **1227.60 MHz**，波长约 24.4 cm。主要承载 P(Y) 码，现代化后也承载 L2C 和 M 码。
*   **L5**：频率为 **1176.45 MHz**，波长约 25.5 cm，是GPS现代化后新增的频段。主要承载 L5 信号，属于“生命安全”频段。

### 🔢 测距码：实现测距与卫星识别
*   **C/A码 (粗/捕获码)**：码率为 **1.023 MHz**，周期 1 毫秒（1023位）。为明码，**供民用**，可用于快速捕获卫星和粗略测距，测距精度约 2.9 米。
*   **P(Y)码 (精码)**：码率为 **10.23 MHz**，周期长达 266.4 天。加密信号，**主要供授权用户（如军方）使用**，测距精度高，可达 0.29 米。
*   **其他现代化码 (L2C, M码, L1C)**：GPS现代化过程中新增的信号，旨在提升民用服务性能（L2C）和增强抗干扰/反欺骗能力（M码）。

### 📄 导航电文：包含定位关键信息的数据包
*   **结构**：按“字 → 子帧 → 帧 → 超帧”的层级结构编排。
*   **基本数据**：以 50 bit/s 的速率连续发送。每 30 秒发送一个完整的“帧”（1500 bit），包含 5 个“子帧”（每子帧 300 bit），每个子帧又包含 10 个“字”（每字 30 bit）。
*   **关键数据块**：
    1.  **第一数据块（子帧1）**：包含**卫星钟差参数、星钟年龄、健康状态**等，用于修正卫星钟的时间误差。
    2.  **第二数据块（子帧2和3）**：包含**广播星历**，即精确描述该卫星自身轨道的参数，用于实时计算卫星的空间位置。
    3.  **第三数据块（子帧4和5）**：包含所有卫星的**历书**、电离层模型参数等。其中历书信息用于快速搜索和锁定卫星，加快定位速度。
*   **遥测字（TLM）和交接字（HOW）**：位于每个子帧的开头，分别用于实现**子帧同步**和提供**时间信息**，以辅助导航电文的解码和P码的捕获。

**协议地球坐标系**，是为了解决地球自转和极移导致的坐标轴不断变化问题，而人为规定某一时刻的地球自转轴和本初子午线方向作为固定参考，从而建立的一个与地球固连且相对稳定的空间直角坐标系。它是描述地面点位置、绘制地图和进行导航定位的基础。

其核心定义包含以下几个关键要素：

1.  **原点**：位于地球的**质心**。这保证了该坐标系遵循地心系的基本规律，例如卫星动力学方程可以简洁地表达。

2.  **Z轴**：指向**协议地球极 (CTP)**。这是一个人为规定的、固定的北极点方向，通常采用1900至1905年期间地球自转轴的平均位置（由国际天文联合会IAU定义），从而消除了地极移动（极移）的影响。

3.  **X轴**：指向**协议本初子午线**与**协议赤道**的交点。协议本初子午线也是固定的，通常基于国际时间局 (BIH) 定义的格林尼治平均天文台方位。

4.  **Y轴**：与X轴、Z轴构成**右手直角坐标系**。即Y轴指向东经90度方向，满足右手定则：`Y = Z × X`。

### 为什么需要“协议”？

地球并非刚体，其自转轴相对于地壳存在微小的周期性或漂移性运动，这种运动称为**极移**（Polar Motion）。如果坐标轴随着地极晃动，那么地面点的坐标（经纬度）就会时刻变化，这对于大地测量、地图绘制和导航来说是无法接受的。

因此，科学家们**“冻结”**了某一特定历元（例如1900.0年）的地球自转轴和本初子午线方向作为标准，所有测量都相对于这个固定的轴系进行。这个人为固定下来的系统，就是协议地球坐标系。而实时变化的、与地球当前瞬时自转轴绑定的坐标系，则称为**瞬时地球坐标系**。

### 协议地球坐标系的实现

一个坐标系的定义是理想的，而实际应用需要一套具体的参考点来体现它。协议地球坐标系通过**国际地球参考系统 (ITRS)** 和其具体实现 **国际地球参考框架 (ITRF)** 来物理实现。

- **ITRS**：是协议地球坐标系的精确几何定义和数学描述。
- **ITRF**：是全球范围内一系列精心选定的、坐标精确已知的**基准站**（通过VLBI、SLR、GPS等多种技术长期观测确定）所构成的网络。用户通过测量与这些站点的相对位置，就能将自己的坐标纳入到协议地球坐标系中。

### 与GPS定位的关系

GPS接收机最初解算出的坐标是**瞬时地球坐标系**下的坐标，因为它是在接收信号的瞬间，以卫星轨道（也是瞬时值）为参考计算出来的。为了输出稳定、可复用的成果（例如WGS-84坐标），接收机或后处理软件必须应用**极移改正**和**地球自转参数**，将瞬时坐标转换到协议地球坐标系。

**常用的协议地球坐标系实例：**
- **WGS-84 (GPS系统)**：其坐标轴指向定义上与ITRS一致，偏差极小（厘米级），可视为ITRS的一个具体实现。
- **CGCS2000 (北斗/中国)**：中国的大地坐标系，也属于协议地球坐标系。
- **ITRF (国际通用)**：最精确、最权威的实现，作为全球参考框架的基准。

总而言之，**协议地球坐标系就是通过人为固定地极和本初子午线方向，为动态变化的地球建立的一个静态、稳定、统一的空间基准**，是实现高精度、全球一致定位的基石。

---
将**天球坐标系**（本质上是一个惯性坐标系，用于描述天体在空间中的固定方向）转换到**地球坐标系**（与地球固连、随地球自转的坐标系），是卫星导航、天文观测和深空探测中的基础步骤。这个转换的核心思想是**逐步消除地球的多种复杂运动**，将空间中的方向矢量“旋转”到地面站心。

转换过程通常分为四个连续的步骤，每个步骤对应一个主要的旋转矩阵：

### 1. 岁差旋转：移除地球自转轴的长期进动
地球像一个旋转的陀螺，其自转轴在空间中绕黄道法线做缓慢的圆锥运动，周期约26000年，称为**岁差**。这个旋转将瞬时天球坐标系的Z轴（指向瞬时天极）旋转到协议天球坐标系（如J2000.0）的固定Z轴方向。

- **旋转矩阵**：P(t)
- **效果**：将天体的坐标从**协议天球坐标系**（如J2000.0）转换到**瞬时天球坐标系**（t时刻的真天球坐标）。

### 2. 章动旋转：修正短周期抖动
叠加在岁差之上，地球自转轴还存在着周期约为18.6年（主项）的微小、周期性抖动，称为**章动**（主要由月球轨道摄动引起）。这一步将瞬时天极精确地修正到其真实位置。

- **旋转矩阵**：N(t)
- **效果**：进一步修正，得到**真天球坐标系**（t时刻的真天极、真春分点）。

### 3. 地球自转旋转：将惯性系转为地球固连系
这是最关键的一步，它消除了地球绕自身轴的自转。旋转角度由**格林尼治真恒星时**（GAST）决定，该角度反映了春分点相对于格林尼治子午线的方位。

- **旋转矩阵**：R(t) 或 S(t)
- **效果**：将**真天球坐标系**转换到**瞬时地球坐标系**（Z轴与瞬时地极重合，X轴指向瞬时格林尼治子午线与真赤道的交点）。

### 4. 极移旋转：固定地极到协议地极
地球自转轴相对于地壳还有微小的移动（约0.1角秒量级），称为**极移**。这一步将坐标轴从瞬时地极（与地壳固连但仍在晃动）旋转到固定的**协议地极**（CTP，如ITRS的Z轴方向）。

- **旋转矩阵**：W(t)
- **效果**：将**瞬时地球坐标系**转换到**协议地球坐标系**（如WGS-84、ITRF）。

---

### 最终转换公式

综合以上四步，从天球坐标系（协议）到地球坐标系的完整转换可以表示为：

$$
\mathbf{r}_{\text{地球}}(t) = W(t) \cdot R(t) \cdot N(t) \cdot P(t) \cdot \mathbf{r}_{\text{天球}}
$$

**实际应用中（如GPS导航）**，该过程往往被简化或反向进行：

- **星历计算**：卫星轨道最初是在天球惯性系中根据力学定律推算的（开普勒轨道根数）。
- **输出坐标**：为了给地面用户使用，卫星导航电文中的星历参数实际上**已经预先融合了岁差和章动模型**，直接给出了卫星在**瞬时地球坐标系**中的位置。
- **用户端处理**：用户接收机解算出的结果位于**瞬时地球坐标系**。为了得到稳定的地图坐标（如WGS-84），接收机必须进行**极移改正**，即应用上述的W(t)矩阵。

### 关键参数来源

这些旋转矩阵（P, N, R, W）所需的时间参数和地球定向参数（EOP）由国际地球自转服务（IERS）发布的高精度模型（如IAU 2000/2006决议）提供，包含在IGS精密星历等产品中。

### 简化理解

如果不关心亚角秒级精度，日常应用常将这个过程简化为：

1.  **天球** → **地球**：最核心的步骤就是乘以一个**地球自转矩阵**（基于格林尼治恒星时）。
2.  岁差、章动、极移仅在需要**厘米级**或更高精度时（如长基线干涉测量、精密大地测量）才必须逐一修正。

**总结流程图：**

协议天球坐标系  
   ↓ (岁差 P)  
瞬时天球坐标系  
   ↓ (章动 N)  
真天球坐标系  
   ↓ (恒星时 S / 地球自转 R)  
瞬时地球坐标系  
   ↓ (极移 W)  
协议地球坐标系 (如 WGS-84, ITRF)

GPS外业测量中，选点（观测站位置的选择）是决定数据质量和最终成果精度的关键第一步。如果选点不当，即使后续采用高精度的处理软件，也很难消除观测数据的系统性误差。

以下是GPS外业选点需要严格遵守的注意事项，主要围绕**保障信号质量、减少误差、提高可靠性**展开：

### 1. 核心原则：确保观测环境"对天开阔"
GPS卫星信号十分微弱，任何遮挡都会严重影响信号接收。

-   **高度角要求**：测站上方视野应开阔，通常要求**高度角15°以上**的范围内不能有障碍物（如树木、建筑物、山体等）。对于高精度测量（如控制网），要求可提高至**10°或更低**。
-   **避开遮挡**：避免选在高层建筑旁、峡谷深处、茂密树林下、大型桥梁下方或隧道口附近。

### 2. 严格规避：远离多路径效应源
**多路径效应**是短基线高精度测量的主要误差源，且无法通过差分技术有效消除。

-   **远离反射面**：测站应远离**高大建筑物、光滑墙面、玻璃幕墙、水面、金属广告牌、钢板、大型车辆、高压铁塔**等能强烈反射电磁波的物体。建议距离至少**50-100米**以上（视反射体大小和表面材质而定）。
-   **避免裸露地面**：如果测站周围是大片干燥、平整的裸土或混凝土坪，也可能产生较强反射，需注意。

### 3. 坚决避开：强电磁干扰源
GPS信号频率（L1、L2等）极易受到同频段电磁辐射的干扰。

-   **远离干扰源**：测站应远离**高压输电线（至少50米）、变电站、雷达站、电视发射塔、无线电基站（特别是大功率基站）、微波中继站、大型电机设备**等。
-   **注意移动干扰**：避免在频繁有大型车辆（特别是配有无线电设备或金属箱体的卡车）经过的路边设站。

### 4. 确保稳定性与安全性：点位基础
GPS观测通常需要连续记录数十分钟至数小时，点位必须稳固。

-   **地质稳定**：选在**土质坚硬、不易沉降、无滑坡或侵蚀风险**的地点。避免选在软土、填土、河岸、边坡边缘。
-   **安全防盗**：对于需要长期保存的控制点，应考虑**不易被车辆碾压、不易被施工破坏、不易被盗窃**的地点，必要时加装保护井或护栏。
-   **避雷措施**：在雷暴多发区，应远离孤立的高地、大树、金属构筑物，必要时设置避雷针。

### 5. 方便作业与联测：提高效率
-   **交通便利**：选点位置应便于测量人员和设备（天线、脚架、电池）到达，减少徒步负重距离。
-   **便于联测**：如果需要将GPS网与现有地面控制网（如全站仪导线点、三角点）或水准点进行联测，所选点位应**与这些传统控制点尽量接近**（例如30米以内），或者有清晰、稳定的通视方向（对于全站仪联测）。
-   **电源与通讯**：如果进行长时间连续观测（如CORS站或静态控制网），需考虑**电源供应（市电或太阳能）** 和数据传输条件。

### 6. 规范标记与记录：成果可追溯
每个选定的点都必须有清晰的标识和完整记录。

-   **埋设标志**：在坚硬地面打桩、埋石或浇筑水泥标志，中心刻有清晰十字或嵌入铜钉。临时点可打木桩并钉铁钉。
-   **绘制点之记**：填写**点之记**表格，记录：
    -   点位编号、名称、等级、选点日期。
    -   详细文字描述（如“距某村庄北偏东300米，某公路里程碑东侧5米”）。
    -   拍摄**点位环视图**（从北方向起，每隔45°拍一张，共8张），直观反映周围遮挡情况。
    -   绘制**点位略图**，标注通往该点的路线和周围永久性地标。
-   **量测天线高起始面**：明确记录天线高量测的起始位置（如天线底部、相位中心参考点等），避免后续处理时出错。

### 7. 特殊场景补充注意事项
-   **高精度静态控制网**：要求点位之间构成的图形强度好（避免所有点几乎在一条直线上），且基线长度应适中（长基线注意电离层差异）。
-   **RTK流动站**：除了上述要求外，还需特别注意**电台或网络通讯信号**是否良好，以确保能稳定接收基准站的差分改正数。
-   **变形监测**：点位应布设在变形区域外的稳定基岩上，且能长期保存、不易扰动。

| 项目 | 理想条件 | 禁止/谨慎条件 |
| :--- | :--- | :--- |

| **反射源** | 开阔、无大型反射面 | 水面、玻璃墙、金属物、光滑地面 |
